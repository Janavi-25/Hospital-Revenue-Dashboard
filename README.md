# 🏥 Hospital Revenue Dashboard – Power BI

## 📌 Project Overview

The **Hospital Revenue Dashboard** is an interactive Power BI report designed to monitor hospital revenue performance and compare revenue trends across time periods, departments, visit types, and shifts.

The dashboard includes headline KPIs, a monthly revenue comparison, a department-wise quarterly revenue table, and interactive filters to help users explore hospital revenue data.

## 🎯 Project Objectives

- Monitor total hospital revenue.
- Track year-to-date (YTD) revenue.
- Review year-over-year (YoY) revenue growth.
- Compare monthly revenue with previous-year revenue.
- Analyze quarterly revenue across hospital departments.
- Explore revenue by visit type and shift.
- Use date and year filters to investigate performance over time.

## 🛠️ Tools & Technologies

- **Power BI Desktop** — dashboard design and reporting
- **Power Query** — data transformation and preparation
- **DAX** — KPI and time-intelligence calculations
- **Data Modeling** — relationships between tables

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)

- **Total Revenue:** Overall revenue shown in the report.
- **Total YTD:** Year-to-date revenue.
- **YoY %:** Year-over-year revenue change.

### 2. Monthly Revenue Comparison

A line chart compares total revenue with previous-year revenue by month to help reveal changes and trends over time.

### 3. Department Revenue Table

A quarterly table displays revenue across hospital departments, allowing users to compare departmental performance between periods.

### 4. Visit Type Filter

Users can filter the report by **Emergency**, **Inpatient**, and **OPD** (Outpatient Department).

### 5. Shift Filter

Users can explore revenue using the **Morning**, **Evening**, and **Night** shift options.

### 6. Date and Year Filters

The date slicer and year selection allow users to focus on particular reporting periods. The other visuals should respond to these filters when their relationships and visual interactions are configured correctly.

## 💡 Potential Business Uses

This report can help hospital stakeholders:

- Monitor overall revenue performance.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `Hospital-Revenue-Dashboard.pbix` in Power BI Desktop.
3. If prompted, configure the data source to point to the original hospital dataset.
4. Explore the dashboard using the date, year, visit type, and shift filters.
5. To refresh the report, ensure the original dataset is accessible and the data source is configured correctly.

**Note:** The original dataset is not included in this repository. Some report features, including data refresh, may require access to the original dataset.
